# Support The Project

## Report Issues

The easiest way to help make Trajectory better is to use it and report issues. Found a bug? [Open an issue on GitHub](https://github.com/dodgerbluee/trajectory/issues).

## Development

If you build software, there are plenty of ways to help Trajectory grow. Pick a bug to fix, improve the docs, or add a small feature. New contributors are always welcome. For contribution details, see the [Development](./development.md) section.
