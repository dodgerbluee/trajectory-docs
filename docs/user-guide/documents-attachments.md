# Documents & Attachments

Upload and organize files like visit summaries, lab results, photos, and vaccination cards.

## Upload a Document

1. Open a child profile
2. Click **Documents** → **Upload**
3. Choose a file, add a title, and save

## Attach to Records

Attach documents to visits, illnesses, vaccinations, or medical events as needed.

## Organize and Search

Use document types and tags to keep files easy to find.

## Export or Share

Download files when you need to share with a provider or school.

### Storage Location

Documents are stored in your Trajectory instance's file storage:
- **Privacy first** - Files never leave your server
- **Your infrastructure** - Stored where you host Trajectory
- **Backed up** - Included in your backup strategy (see [Operations](../operations.md))

### Storage Limits

Check with your administrator for:
- Maximum file size per upload
- Total storage quota
- Allowed file types

:::tip Check Storage
Administrators can view storage usage and set limits. See the [Operations Guide](../operations.md).
:::

## Sharing Documents

Export or share documents with healthcare providers or schools.

### Exporting Documents

1. Select the documents you want to share
2. Click **Download** or **Export**
3. Share the downloaded files as needed

When sharing documents outside Trajectory:
- ✅ Use secure methods (encrypted email, secure portal)
- ✅ Share only what's necessary

## Common Document Workflows

### Uploading Vaccination Cards

1. Take a photo of the vaccination card
2. Upload to Trajectory
3. Tag with "vaccination card"
4. Attach to individual vaccination records
5. Available for school enrollment

### Storing Prescription Images

1. Photo the prescription at the pharmacy
2. Upload to Trajectory
3. Link to the related visit
4. Tag with medication name
5. Reference for refills

### Organizing Test Results

1. Upload lab results PDF
2. Tag with test type and date
3. Link to the visit where it was ordered
4. Add notes about results in description
5. Easy to reference at follow-up appointments

### Documenting Rashes or Injuries

1. Take photos showing the condition
2. Upload with descriptive titles
3. Link to illness or injury visit
4. Track progression with multiple photos
5. Show to doctor at follow-up

## Tips for Managing Documents

✅ **Upload immediately** - Don't wait, upload documents as soon as you get them

✅ **Use descriptive names** - "Chest X-ray 2026-02-04" instead of "IMG_1234.jpg"

✅ **Tag consistently** - Use the same tags for similar documents

✅ **Link to records** - Connect documents to visits, illnesses, events

✅ **Regular cleanup** - Review and remove duplicates or unnecessary files

✅ **Take photos of physical documents** - Vaccination cards, prescriptions, etc.

✅ **Organize by child** - Keep each child's documents in their profile
