# Managing Illnesses

Track symptoms, medications, and recovery so you have a clear timeline to share with a doctor.

## Create an Illness Record

1. Open a child profile
2. Click **Add Illness**
3. Add name, start date, and status
4. Click **Save**

## Log Symptoms, Medications, and Temperature

Add symptoms, doses, and temperature readings as needed during the illness.

## Link Visits

Use **Related Illness** on a visit to connect the timeline. See [Recording Visits](./recording-visits.md).

## Update Status

Set the illness to **Recovering** or **Resolved** when it ends.

## Illness History

Use the **Illnesses** tab to view or filter past episodes.

View summary statistics for health trends.

### Available Statistics

- Total illnesses per year
- Average duration
- Most common symptoms
- Medication effectiveness
- Recovery time trends

## Editing an Illness Record

Update illness information as it progresses.

### Editing Details

1. Open the illness record
2. Click **Edit**
3. Update any fields
4. Click **Save Changes**

:::tip Keep It Updated
Update the illness record daily during active illness to maintain an accurate timeline.
:::

---

## Deleting an Illness

Remove illness records if needed.

### Deleting an Illness

1. Open the illness record
2. Click **Delete** (usually in settings menu)
3. Confirm the deletion

:::warning Permanent Action
Deleting an illness removes all associated symptom logs, temperature readings, and medication records.
:::

## Tips for Illness Tracking

✅ **Start immediately** - Create the record when symptoms first appear

✅ **Log temperature regularly** - Track fever patterns, especially if medicating

✅ **Note medication times** - Helps prevent double-dosing and tracks effectiveness

✅ **Take photos** - Document rashes, injuries, or visible symptoms

✅ **Record everything** - Even small details can help identify patterns

✅ **Update status** - Mark when recovering or resolved for accurate history

✅ **Link to visits** - Connect doctor appointments to illness records

## Common Illness Scenarios

### Tracking a Cold

1. Create illness record: "Cold"
2. Log symptoms: Runny nose, cough, congestion
3. Track temperature if fever develops
4. Record any medications given
5. Note when symptoms improve
6. Mark resolved when fully recovered

### Tracking Stomach Bug

1. Create illness record: "Stomach virus"
2. Log vomiting/diarrhea episodes with times
3. Track fluid intake
4. Monitor for dehydration signs
5. Link to doctor visit if needed
6. Track recovery timeline

### Tracking Ear Infection

1. Create illness record: "Ear infection"
2. Note symptoms: Ear pain, fever, fussiness
3. Link to doctor visit where diagnosed
4. Log prescribed antibiotics with schedule
5. Track fever reduction
6. Follow up with visit if needed
